# Sky 0.3.18 地图编辑器实现清单

当前实施目标：Objects.level.bin 第一；BstBaked.meshes 和 Avatar 模式第二。先逆向原加载、创建、注册、更新和销毁整体调用链，再按原依赖从基础类向功能类推进。引用到未实现的玩法、交互、UI、贴图、音频、shader、BstBaked 或 Avatar 功能时一同恢复。最终目标为原游戏逻辑 100% 还原；五个 BstBaked 段仍以各 9/10 为真机验收前阶段目标，最后一项为真机与原游戏校验。 [原调用主链](Objects原调用主链与依赖推进.md)。

目标：Windows x64 桌面编辑器；输入为本地 Sky Data；读取、编辑并回写游戏原格式。原版行为必须有可执行文件或原始 shader 的证据，不将编辑器预览替代游戏逻辑。

## 状态定义

- 已验证：有自动检查或逆向证据；具体范围写在条目后。
- 已实现：代码已完成，尚未覆盖目标环境验证。
- 待逆向：原版算法尚未确认，不能宣称支持。
- 待实现：证据和接口已明确，代码尚未完成。
- 待验证：需要 Windows 或原游戏运行确认。
