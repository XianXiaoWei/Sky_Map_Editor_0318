# 冥龙移动前半段与打包门槛

本阶段恢复原 DarkCreature.Update 的 **0x10026ddb0..0x10026e7da**，共 439 条原指令，止于 Model.SetTransform 及模型回调函数／owner 写入。这是原外层更新的前半段，不代表完整冥龙行为已经完成。

恢复范围包括状态分支生成加速度、巡逻渐变、目标有效性和返回状态，两个辅助边界更新，速度平滑及限速、实际速度与位置积分、朝向基和缩放后的模型矩阵。原完整出现辅助函数 `0x100270010..0x100270310` 与原完整 Motion.FollowRail `0x10062e300..0x10062e430` 已恢复；组合入口使用真实 Motion.Seek、SwitchRail、出现及轨道跟随实现。

原程序独立对照 587 组，完整调用者内存与有序服务共比较 **80,561,452 字节、5,656 次外部调用，零差异**。案例包含各状态／目标、无效玩家与64鸟槽边界、出现高度和音效版本、巡逻渐变、返轨阈值、开放／闭合轨道、速度和位置、朝向临界值及上下极点、NaN／无穷／有向零、显式私有W、回调更换模型／边界owner、轨道时间与运动字段别名、随机有限值及连续帧。另有完整组合入口直接运行生产组合函数，没有替换其中的实际辅助消费者。

证据固定原可执行文件 SHA-256、完整函数边界及前半段精确停止地址。对照执行原 x86_64 机器码；原 math 调用输入和返回值显式记录重放，不宣称 JavaScript 与 macOS libm 等价。调色板、packed delta 的 W 及轨道容差路径没有写入的私有 W 由调用者明确提供。原模型变换服务返回后会重新读取模型指针，回调字段写入实时模型。
