# 生物巡视、蝴蝶与性能修复

本次范围是蝴蝶、螃蟹贴地、冥龙巡视投影和生物查询成本。Windows 包不包含 Data；原地图只读，实际五图验证检查文件哈希不变。

## 螃蟹

保留原 Load／自主 AI／转向／动画策略。移动前先水平扫墙，落脚射线仅从前一高度上方 0.1 发出，拒绝垂直面、超过步高的屋顶和过大落差。小于 0.001 的地面高度误差保持旧高度，避免平地数值抖动。斜坡正常通过；没有可走落脚时停止，防止在墙底切换到墙顶。邻居指针使用 Map，避免每次类型查询重新扫描所有螃蟹。

地面接触是编辑器适配，尚没有完整原游戏重力／首次落地；原图内不满足接触条件的实例可能保持位置。没有把这些实例计作完整物理恢复。

## 冥龙巡视

墓土保存的冥龙 startInRest 为 1，而原唤醒事件尚无联网／玩家服务。为保留编辑器原有自动播放行为，播放预览调用已恢复的 awake 接口；还原恢复休眠，重播再唤醒。这是明确的编辑器入口，不修改保存参数、不假称原地图事件链已恢复。

原执行顺序来自 `DarkCreature::Update`：0x10026bea1 调 Alert，0x10026c146 再调运动更新。恢复原固定 10 度巡视参数（0x3e32b8c3），沿原眼部骨骼与 spotlight 碰撞目标确定落点和半径。

唤醒验收发现原 Motion.FollowRail 使用的 Rail +24 弧长仍为构造时的零，导致除零并产生 NaN。现按原 OnLevelLoad 的 32 次细分构建弧长表并写回该字段，原 FollowRail 内核保持不变。

使用原 `LightShaftCone_01_CompOcc_CompEdges` 模型，其前向为负 Z。地面圈的 24 段边缘分别查询最近表面，遇遮挡或缺失地面不绘制该段；约每秒 15 次更新投影，避免每个渲染帧重复 49 次查询。

原眼部／CloudDrop palette 不等同于已证实的地面圈颜色。现有圈的颜色、透明混合和表面网格是编辑器适配；CloudDrop 已注册但尚未接原下游云绘制，因此不声称完整巡视像素还原。

## 蝴蝶

使用地图保存的 SpawnMotes／MoteParams、原生成时序与随机空间、`CharFlyBeingMiniAAnim` 和原 `Mote0.vert`／`Mote0.frag`。蝴蝶平原自动生成 117 只；关闭的事件保持关闭。每只具有独立位置、速度、转向和扑翼相位，采用原 wander／steering 的数值核心与 Marker 区域适配。

核对原程序后修正此前的参数误解：+0x34c 是离开 LightHouse 的计时，而非玩家距离（0x100477f60）；普通速度在光照／20 秒计时条件下选 2 或 8（0x100476415）。状态的 0.5／2 秒分界也来自该计时。完整 LightHouse 服务仍待接入，当前默认未被光源照亮；可由明确的光源服务供给该判定。

原视觉 0x1004771b0 使用距离平方插值 0.08～0.32 的尺寸，普通 brightness 为 1；原初始化给出独立 8～11 的扑翼频率，phase 按 2π 环绕。没有把 MoteParams 的碰撞 radius 直接当作模型尺寸。原程序保持近处小尺寸并放大远处模型，和运动速度是不同的参数。

顶点流为 72 字节，沿用原色值、世界坐标、朝向、尺寸、亮度与 phase。初始导出、增量 IPC、shader 预编译和 Windows Vulkan 属性校验均覆盖该格式。每个生成器缓存自己的批次，未产生蝴蝶的生成器不重复上传空几何；重播复用内存。当前最多 256 只。

携带、任务、轨道尾事件／换参数、完整风／光源／生死交互与联网仍未恢复。本次目标是地图里的独立蝴蝶预览，不能作为完整原游戏 Mote 类复刻。

## 性能与验证

场景 AABB 树先筛选，再使用不改索引的原网格 BVH。保留最近命中、face ID 和移动／旋转／缩放／顶点编辑后的查询语义；静态场景不重复重建树。

帧率验收发现螃蟹 idle／run 切换重新克隆几何体，改变 geometry UUID，使一次动作切换触发整图／材质重上传。现在同一实例与同一资源切换动作复用自有几何及索引，仅更新姿态；动作时钟正常重建，停止仍归还共享源几何。回归检查动作切换没有新增场景提交。

动画顶点不变时不上传、不递增 GPU revision；隐藏实例不计算蒙皮。单帧动作复用蒙皮结果；仅对已经达到固定点、没有 action 延时／混合的时钟跳过重复分配。原时钟字节对照仍通过。局部基准里的静止动画未稳定体现加速，不把它计作新的性能倍数。

全项目 735 项回归通过；最终 Mote 和动画时钟更正后的 24 项检查，以及巡视／弧长的 15 项检查通过，TypeScript 检查通过。33 地图 2,380 次 shader 请求在 PATH 为空、用户缓存为空时通过，包含 MoteAnim。

五图先完成基础回归；最后仅影响冥龙的唤醒／轨道修正再单独复验墓土，各图记录实际测试的构建哈希。最终碰撞基准、五图实际视口、整图性能、打包与独立 ZIP／ASAR／PE 核验数据分别记录在 `creature-contact-performance.json`、`basic-creature-preview-smoke.json`、`performance-creature-latest.json` 和 `basic-creature-package-verification.json`。局部 CPU 倍数不代表整图 FPS；测试设备是 Android／PRoot 的 llvmpipe 软件 Vulkan，不能推算 Windows 显卡的 120 FPS。

原程序 SHA256：`3fa493e2542638299fd54d64e1b62aeb5b81c8f290176d955c3e38a27fa72b20`。原参数证据由 SHA 门控 `tools/native.py` 读取；未运行原游戏程序。

最终动作几何复用修正在原蟹场景做当前构建导航复测；晨岛的有效导航记录来自该最后修正前。帧率文件对两次测量注明来源，最终运行包哈希来自蟹场景复测。

最终实测：1,200 网格／256 射线的查询中位数 322.94 → 6.24 ms，约 51.77 倍。最终蟹场景在 336×408、完整效果、llvmpipe 软件 Vulkan 下为 1.21 FPS，后 4 秒约 1.51 FPS；导航场景和材质上传均为 0，几何仅增量更新。此前动作切换重传导致测量中发生长停顿，该失败记录不用于宣称严格的整图 FPS 倍数。晨岛有效记录为 1.67 FPS，但来自最后几何复用修正前。整图 120 FPS／10～20 倍与 Windows 真机表现未验证。
