## OnRegion

完整 placement、Enable、Update 和 PlayAnimation placement，以及原容差区域布尔入口，共 **373 组、128,043,024 字节、30,273 次服务调用，零差异**。每组比较完整调用 arena 与边界调用顺序；Update 中矩阵乘法保持原代码，实际区域布尔函数也单独及组合比较。

- 世界原点和无序的平方长度比较跳过检测。
- totalHits 按玩家与区域的命中对累计；requireAllRegions 另按区域去重。
- onEnter、fireOnce、fireEveryFrame、local/remote、camera/object 模式、最小人数、全部玩家、全部区域、16 字节 SIMD 去重归约及有符号计数阈值已覆盖。
- 真实回调可修改 Clump、字段、对象引用和目标，重读位置保持原顺序。
- fallback 位置的 W 明确由调用者提供；构造不写的私有字段保持原样，Enable 才清两个计数。
- `0x10078d450` 包装器仅消费包含结果。其被调用函数还向私有临时内存写最近点；没有声称恢复独立最近点 API。

AvatarBarn、camera、metadata、虚空间方法、Clump 启用与 Event.Start 在独立原对照中为明确边界；地图组合验证使用实际 Marker 空间内核、原 EventBarn、Delay、PlayAnimation 和动画序列消费者。
