# 视口飞行相机

先点击视口取得键盘焦点。

| 操作 | 效果 |
| --- | --- |
| W / S | 沿相机朝向前进 / 后退 |
| A / D | 向左 / 向右移动 |
| Q / E | 沿世界 Y 轴下降 / 上升 |
| 按住右键拖动 | 保持相机位置，改变看向 |
| Shift + 移动键 | 加速 |
| 右键单击 | 打开原 Meshes 菜单 |

移动速度随观察距离调整，同时按多个方向键保持总速度。中键轨道旋转、Shift+中键平移、滚轮、F/Home 和右上角相机按钮继续可用。视口焦点下 S 是后退；对象缩放可用工具栏按钮。

输入框、打开的对话框、变换/笔刷操作和失去焦点时停止飞行。控制只移动编辑器相机，不改变地图资产。右键抬起、取消或失焦会释放捕获并恢复轨道控制。

相机帧缓存按原生使用的 float32 矩阵判断变化，避免 OrbitControls 的双精度微小变化在暂停后反复推进云时间历史。只有云、没有地形的地图现在也能推进动画；暂停导航会补绘历史帧。诊断显示模式保持静止。

实际窗口验证见 [fly-camera-smoke.json](fly-camera-smoke.json)，新包内的飞行及云历史检查见 [preview-package-smoke.json](preview-package-smoke.json)。原相机采样的独立逆向证据见 [相机采样与云地形时间历史逆向](相机采样与云地形时间历史逆向.md)。
