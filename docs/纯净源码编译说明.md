# 纯净 Windows 源码编译说明

本包包含当前修复后的 TypeScript、C++、GLSL 源码、锁定依赖版本、测试与静态参数。不包含原游戏 Data／程序、node_modules、dist、release、预编译 SPIR-V、Electron 运行包和 Android host。

## 构建 Windows x64

现有 Windows 原生构建脚本使用 Linux 到 Windows 的交叉编译工具链。推荐在 Ubuntu 或 Windows 的 WSL Ubuntu 内编译。准备 Node.js 22 或更新版本、npm、Python 3 和下列工具：

```bash
sudo apt-get update
sudo apt-get install -y python3 g++ g++-mingw-w64-x86-64 binutils-mingw-w64-x86-64 libvulkan-dev glslang-tools spirv-tools
npm ci
npm run build:windows
```

构建产物位于 `dist/`，Windows 原生渲染程序为 `dist/native/sky-vulkan.exe`。编译本身不需要 Data。原生脚本按当前工具链读取 `/usr/include/vulkan` 和 `/usr/include/vk_video`，请在 Linux／WSL 环境运行；此说明未宣称已经在 Windows 真机上验证。

源码中的 `docs/beamo-rsqrt-capability.bin` 是模型数值计算所需的静态查找表，`src/renderer/author-appreciation.png` 是作者页面图片，均为应用输入而非编译产物。请保留这些文件。

## 地图着色器与运行

在具备合法可用的 Data 后，可生成地图视口使用的预编译着色器，避免运行机器缺少 `glslangValidator` 时地图加载失败：

```bash
export SKY_DATA='/你自己的路径/Data'
npm run precompile:viewport
npm run verify:viewport:shaders
```

地图着色器源由原资源目录提供，因此这一步需要使用者自行配置 Data。本源码包没有附带原资源或现成的编译缓存。

Linux 本地运行可使用 `npm run build` 和 `npx electron .`。Windows 交叉编译后的原生程序应搭配 Windows Electron 运行时使用。独立运行包的打包脚本以及此前的实测证据也随源码提供；其中部分验收和研究脚本需要外部游戏资源、原程序或指定测试环境，不能在缺少这些输入时重跑。
