## 本次接入

本次扩展后为 25 类、2482 个环境相关对象的正常原父构造、原存储大小、保存 POD/字符串与已恢复引用进入共享运行地址。Marker、Clump、Float、Rail、LevelMesh 依赖共用地址，另有 76 个 SpawnMotes 的真实 160-byte 正常父构造和四列原变换读写；未恢复的引用、复合数组、枚举和默认缓存保留明确诊断。原 120 个 Wind（含 26 个 Rail 引用）接入地形/模型贴图及实体云运动，使用共享帧时间；边界/交互力、Rail 完整生命周期和原数学库仍为缺口。

SetEnvDefault、SetEnvHull、SetWind、SetRainParams、SetOceanRender、SetEmitterFlowRail 和 DropOcclusion 使用原 EventBarn。雨量三过渡、相位、强度与原大小写 Rain 匹配已接入参数状态，雨的掉落/碰撞/音效/绘制仍待恢复。521 个 PointLight 使用每地图原 256 槽池，普通 Ambience 点光参数换算传入主视口；局部点光投影/阴影并未据此完成。

DropOcclusion 恢复正常 Load `0x1002ce410`、Unload `0x1002ce460`、OnEnabled `0x1002ce490`、Update `0x1002ce7b0`。原独立 alpha、逐目标启用、不同淡入/淡出 snappiness、实时 Float、变换、半径、tint 与参数重读均保留。63 个真实根进入地图共享状态；另一个根引用 9 个 SpawnMotes 对象，其变换已恢复，原 Event 启用与 Emitter/Mote 生命周期尚未接入，明确阻断。

原 ObjectBarn 路由 `0x1004d3940` 只处理 type=2，强度乘 **-0.5**；原 CloudBarn `0x100416140` 使用 512 个 48-byte 槽，保留原浮点阈值、色彩亮度过滤、拒绝分支和未写字节。该队列已经连接共享 owner；后续 cloud drop 世界采样及 GPU 消费者仍未接通。

暂停仅冻结运行事件的 Update 和已发出记录，保留 enabled/alpha/启动次数；恢复继续现有状态。停止和地图切换执行已恢复的原 Drop 卸载、清空 alpha 指针和点光池。逻辑图 Float 以 uint32 位模式传入相同环境运行存储，原文档不会被运行修改。JS logf/expf 与分配/metadata/日志仍为明确适配服务。
