# 自然动画与鸟群引导续接（2026-11-24）

本轮接通有完整内嵌动画资源的 `LevelMesh` 动作预览。选中模型，打开“模型动作预览”，选择原 AnimationList 中的动作并播放。每个模型实例拥有独立请求时钟、循环符号掩码和几何；暂停冻结时间，停止还原原几何，切图释放预览。没有自动给 BirdV2、Crab 或 DarkCreature 选择／切换 AI 动作，也没有分配替代游戏 Model。

`ResourceModelAnimationPreview` 使用此前独立核验的原命名请求、0x70-byte clock、四帧采样、骨骼矩阵和位置／法线蒙皮消费者。实际动作范围、速度与循环来自保存的 AnimationList；不播放猜测的唯一片段。有镜像、additive、非零 easing 或外部骨架依赖的动作暂不可预览。连续法线归一化明确采用编辑器 JS 倒平方根服务，不能称动态 RSQRTSS 已与原 CPU 逐字节等同；已有默认姿态的原数学能力表和核验保持不变。

已验证鸟 `critterMove`、遥鲲 `critterIdle`、螃蟹 `run`、动画花 `closedLoop` 的逐帧原轨道产生不同蒙皮。螃蟹 `idle` 是单帧，推进时钟仍保持原姿态。当前冥龙内嵌 pack 未匹配到可用动作，保留动作表／动画组依赖。此预览只取一个动作姿态，完整主／次级混合、序列、根位移提取、声音／发射器和自然 AI 更新继续待接。

动态 packed position/color 和 SNORM normal 经新增实例 IPC 提交到实际 Vulkan 模型批次，保留 UV、颜色、烘焙、索引和模型矩阵。原生协议 29 复用现有 `MaterialRenderer.geometryBatch`，逐项保留没有变化的绘制；GPU fence 后写入已有顶点缓冲，材质、管线、descriptor 和贴图不重复装载。原生启动描述新增 dynamicGeometry 能力；旧版原生程序缺少该能力时，完整重传材质批次，不发送未知协议。场景／材质／拓扑变化仍走原完整提交。输入身份、长度、重复项和非有限坐标先统一检查，再写入。顶点流替换后，缓存的局部／世界包围盒与透明排序中心同步重新计算；回归覆盖动画跨越视锥和透明距离变化。

`ReleaseBirds.OnEnabled` `0x1001aa870` 与 `DetachFromBirdGuides.OnEnabled` `0x1001aa480` 已恢复。释放事件清除该鸟的原字段，调用 secondary forced FadeSequence，duration 0.3、delay 0，设置模型字段，然后以玩家物理位置和鸟虚 GetPos 的 XYZ 平方距离严格比较原保存阈值，逐鸟递增统计；没有把原比较转换成平方根或将阈值再平方。Clump count 捕获与回调后的实时引用／范围检查保留。

脱离引导事件在鸟的原 guide-active 字段非零时访问全部 16 个 Avatar 槽，先检查 active，再调用虚 GetEnabled。引导引用使用原 generation 检查，对照该鸟四个实时指针；有效匹配才按原引用 Set 的版本计数、dirty／timeout 字段解除绑定。保留 null/stale 引导与零槽匹配的原行为，不额外清除鸟自身 guide-active。原 Avatar 槽、active、guide Get／Set 和 require-avatar 断言子函数一起执行了原程序对照。

133 组包含全部七个保存事件配置、空／缺失 Clump、失败 cast、缺少 Avatar、严格距离边界、NaN、回调替换模型／Clump／引导、计数变化、版本溢出与 16 槽玩家分支，共 61,560,380 字节、1,054 次有序服务调用零差异。见 [原对照](bird-guide-oracle.json) 与 [函数 SHA／边界](bird-guide-native.json)。数学、动画 FadeSequence、Avatar enabled／选择、统计、metadata 和 Event.Start 的服务范围明确，不以此宣称完整生物／玩家 owner 已恢复。
