# 相机采样与云、地形时间历史

本次恢复原 CameraSystem 的八相位全尺寸采样、32 项半尺寸顺序、高斯采样核，以及上一帧投影的修正。此前预览显式采用零场景抖动，现在地形、裙边、CloudCore 和静态几何使用同一个原采样投影；深度处理、云射线与 FogUpsample 使用各自对应的原采样参数。时间抗锯齿使用当前相位的角点。

## 原程序证据

原程序 SHA-256 为 `3fa493e2542638299fd54d64e1b62aeb5b81c8f290176d955c3e38a27fa72b20`。反汇编见 [CameraSystem](../evidence/temporal-corners-1001e1400.asm)，uniform 绑定见 [CameraSystem 初始化](../evidence/temporal-uniforms-1001de020.asm)。

`0x1001e1447` 读取 Compositor 帧号；帧号与 7 决定八个全尺寸点：

| 相位 | 原采样点 X/Y | 像素偏移 X/Y |
| --- | --- | --- |
| 0 | 4 / 2 | 0.0625 / -0.1875 |
| 1 | 2 / 5 | -0.1875 / 0.1875 |
| 2 | 6 / 0 | 0.3125 / -0.4375 |
| 3 | 1 / 3 | -0.3125 / -0.0625 |
| 4 | 5 / 6 | 0.1875 / 0.3125 |
| 5 | 3 / 1 | -0.0625 / -0.3125 |
| 6 | 7 / 4 | 0.4375 / 0.0625 |
| 7 | 0 / 7 | -0.4375 / 0.4375 |

第三个点由 `vmovss/vmovlps` 加载，Y 为零；不能把相邻的字面量 5 当作其 Y。像素偏移按 `(point + 0.5) / 8 - 0.5` 计算，clip 位移为 `2 * offset / viewportSize`，`u_jitter` 为 clip 位移乘 -0.5。

`0x1001e1b96..0x1001e1c08` 以帧号与 31 查询 `0x100aaf450`：

`0,1,2,3,0,2,1,3,1,0,3,2,1,3,0,2,2,3,0,1,2,0,3,1,3,2,1,0,3,1,2,0`

低位和次低位选择 X/Y 的正负半像素，分别除以全尺寸宽高后写入 `u_jitterHalf`。它与八相位全尺寸采样不是同一套数据。该值参与 signed-depth 的 2×2 选点、Gather 通道置换、Quarter UV 与云/雾采样。

`0x1001e157e..0x1001e1a3d` 对当前偏移附近的 3×3 点计算 `expf(-2.29 * radiusSquared)`，按原顺序累加、归一化，再计算四个成对双线性角点及四组权重、中心权重。不能约掉归一化，因为原 float32 舍入会变化。

`0x1001e1daa..0x1001e1df8` 调用原矩阵逆与乘法，产生 `currentTranslation * inverse(previousTranslation) * previousViewProjection`。必须保留已经舍入的上一帧矩阵。只把上一帧原矩阵传给 MotionGen，会把纯抖动变成假运动；重新从无抖动旧相机建矩阵也不保持原计算顺序。

原全局字节 `0x100c990d0` 置位时，场景投影变为居中、半尺寸采样为正半像素；高斯核仍按原相位生成。本次保留并验证这一分支；未推断该全局字节在完整游戏中的设置来源。

## 对照与视口接入

[camera-jitter-oracle.json](camera-jitter-oracle.json)：512 组输入、42,496 个 float32 分量全部逐字节一致，包含八种尺寸、32 个帧号、两种全局标志分支、显式旧参数及非平凡矩阵。原代码和字面量保持不变；帧号/标志读取接到明确输入，expf 绑定到 Linux libm 并记录参数和返回值。生产 Math.exp 的 float32 结果独立比较也通过。原矩阵乘法及上一帧修正链均直接执行对照。

[camera-temporal-check.json](camera-temporal-check.json)：生产 Vulkan 深度与 MotionGen/MotionDilate/TemporalAa 连续 32 帧，覆盖八种场景相位与四种半尺寸位置。有符号 2×2 深度选择及最小深度零差异，纯色区域零变化；静止运动最大误差小于 0.0001（输出单位为 UV × 1024），明确相机平移的运动输出误差小于 0.001。相机切换使用明确的 cameraCut。

[viewport-camera-sampling-check.json](viewport-camera-sampling-check.json)：Dawn、Prairie_ButterflyFields、Sunset 各完成八帧原采样管线检查。全量地图检查记录在 [viewport-cloud-all-maps-check.json](viewport-cloud-all-maps-check.json) 和 [viewport-terrain-maps-check.json](viewport-terrain-maps-check.json)。画面对照见 [cloud-camera-compare.json](cloud-camera-compare.json)。

编辑器使用完成帧计数驱动原序列，地图重建后从零开始；这不声明与游戏进程全局帧号一致。尺寸变化清空云和时间历史，相机导航按编辑器规则视作 cameraCut；暂停仍保持 shader 时间与随机样本，必要补绘会推进采样相位。原相机创建、出生位置、完整更新生命周期仍未还原。

完整风场、光照/自动曝光、自动云粒子、真实 Visibility、移动模型 Motion 列表、原 Metal 舍入及 Windows/原游戏画面对照仍未完成。已有严格采样与 half/混合失败报告保持原样，本次执行成功不消除这些缺口。五段检查项比例不因此自动增加。
