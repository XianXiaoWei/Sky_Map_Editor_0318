# GT 1030 完整效果性能优化

2026-11-22，0.3.6。保留白屏修复后的普通不透明窗口和画布显示，继续使用原资源、原材质及已接入的 Vulkan 深度、实体云、云片、雾、运动向量、时间抗锯齿和 Tonemap 阶段。

## 用户设备的线索

用户确认是硬件渲染：约 500×500 时 200 ms、5 FPS，约 800×800 时 500 ms、2 FPS。像素数增加 2.56 倍，耗时增加约 2.5 倍，指向逐像素着色、图像复制或显示传输。这个关系不足以确定某一个 shader 就是用户机器上的全部瓶颈；不能用提高目标 FPS 数字解决它。

## 改动

- **硬件云纹理恢复原生滤波。** 原 AIR 对照适配器为了避开软件 Vulkan 的 UNORM8 插值截断，手动读取八个邻点并进行 float32 三线性插值。此前硬件也用了这个适配器。现在硬件使用原生 `textureLod`，保留原纹理字节、单层 LOD0、linear、clamp/repeat 参数；稀疏网格保留原精确最近点寻址。软件 Vulkan 继续使用原 float32 对照插值。一次线性采样从八次显式邻点读取变成一次原生采样，不能由此推算整帧提速八倍。原生滤波精度可与软件 float32 插值有差别，这不是原 Metal 全图等价验收。
- **最终图像在 GPU 转成 RGBA。** 硬件最终读回由每像素 16 字节浮点图降为 4 字节显示图，减少 75% 的最终图像传输字节。整数阈值表保留现有 sRGB 的字节舍入；中间 HDR 不走 IPC。软件 Vulkan 使用 CPU 阈值转换。普通画布显示和白屏恢复启动方式保留。
- **曝光样本批量收集。** 硬件一次 compute dispatch 收集原来的 half 样本，替代约 2048 个 image-copy regions。原生 CPU 的 double 亮度求值和两次 GPU 提交仍保留，没有假称恢复了原游戏完整曝光反馈。
- **资源和附件复用。** 静态纹理、shader、几何摘要缓存；变化的 uniform、动态云片几何和可变纹理继续按内容更新。同格式、不翻转的附件直接采样，其余转换保留。自适应尺寸切换时保留上一张完整画面，等新尺寸图像完成后同步替换尺寸和像素，避免等待中画布闪空。
- **调度和尺寸。** GT 1030 以 60 FPS 为预算，内部长边从 960 开始、范围 384–1600；其他画布硬件从 1280 开始、范围 384–1920；软件从 480 开始、范围 128–640。严重超时时三帧采样后降尺寸，短冷却 500 ms，持续余量才恢复细节。模拟时间独立，所有已接入效果保留；低分辨率会使画面变软。硬件画布完成后调度下一帧，始终只有一个渲染请求。
- **实际 GPU 分段计时。** 支持 Vulkan timestamp 的硬件每帧记录地形/模型、深度/云雾、曝光采样、雾重算、运动/TAA/调色、历史复制及最终传输。右下显示 GPU 总耗时，鼠标停留显示主要分段。计时不增加等待，不支持时自动忽略。驱动和验证层的 stdout 日志与二进制帧管道分开，避免日志污染导致视口停止。

## 读取新版计时

运行新版独立 ZIP，选择原 Data，在原先卡顿的地图上观察右下角。将鼠标停留在 FPS 上，读取 `GPU`、`地形/模型`、`云雾/深度`、`抗锯齿/调色` 和 `显示传输` 的毫秒值。

GPU 耗时接近总耗时，说明大部分时间仍在图形工作；某个分段占比很高，就继续优化该段。GPU 耗时显著低于总耗时，则需检查主进程准备、管道、CPU 转换和画布显示。时间取自用户实际设备，不能用本机软件 Vulkan 的数值替代。

## 验证及性能边界

本版最终构建、测试、图像对照、原资源哈希和验收范围绑定在 `gt1030-performance-verification.json`。

原生滤波适配器与直接 Vulkan `textureLod` 的 128 次查询逐分量一致，覆盖 R8/RGBA8、最近点/线性、clamp/repeat、边缘及越界坐标。软件设备的原生滤波与理想 float32 插值最大误差约 0.00825，单独记录在 `cloud-hardware-filter-check.json`，没有放宽或覆盖旧 AIR 对照测试。

完整链分别验证保守传输/优化传输、原生云滤波与 CPU 参考图。真实 Dawn、SkyHub2、WorldEmpty 覆盖动画、相机变化、非整齐尺寸、换图、重启。对照双方采用相同云滤波策略；软件对照与硬件原生滤波不宣称逐字节相同。Vulkan 同步验证覆盖 compute 读回、附件和 timestamp 查询。

另以 256×144 同尺寸比较传输路径，排除初始化、重启和缩放帧，取三个稳态帧的中位数。这是强制运行硬件 compute 路径的软件 Vulkan、LLVM 优化关闭的验证环境：

| 地图 | 保守传输 ms | 优化传输 ms |
|---|---:|---:|
| Dawn | 639.14 | 670.88 |
| SkyHub2 | 479.85 | 500.94 |
| WorldEmpty | 297.55 | 303.76 |

该测试没有证明总帧时间提高，硬件 compute 在此软件设备上略慢；软件默认不启用这些 compute 核。减少分辨率、减少字节量、减少显式纹理读取与 Windows 真机帧率分别记录，不把任何一项当作已达到高帧率的证据。

目前没有用户 GT 1030 的新版实测，几十或几百 FPS 目标尚未验收。原水、局部光影、完整 Model/Scene/Objects 生命周期及原游戏完整画面仍待恢复。
