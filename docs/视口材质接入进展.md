# 2026-11-15：原地形材质接入实际视口

默认材质模式已经运行真实地图的原地形/裙边 GLSL、贴图与烘焙顶点属性。天空背景使用静态地图环境和球形大气，太阳使用原 Sun shader。完整游戏画面尚未还原。

## 实际改动

- 从原表面分批生成 Vulkan 绘制列表，按基础层、贴花、裙边顺序提交，合并相同材质批次并保留索引顺序。
- 保留原 SNORM4 法线第四分量、两组材质字节、三组照明字节与裙边附加属性；原参数来自 MaterialDefBarn，不从同 ID 的 LevelMaterial 对象借参数。
- 直接解码 PNG 的原 RGBA，避免系统位图接口预乘 alpha 改动透明像素中的法线/材质数据。加载实际原贴图，保留显式 gamma 和寻址配置；完整原 mip/aniso/default 加载策略仍待恢复。
- 原 shader 输出在共享 RGBA32F 颜色附件与 D32 深度附件中绘制，贴花/裙边在线性颜色中混合，最终进行明确的预览曝光、倒数曲线与 sRGB 显示适配。没有把亮部提前截断到 8 位。
- 相机变化更新已有 uniform，环境组变化才重建天空 probe 和材质资源。可见草/沙材质时约 10 Hz 更新原时间/纹理漂移；暂停和属性模式停止动画及无变化帧的重复提交，切图归零。
- 修复天空新增 HDR 参数未传递导致启动失败的问题。
- 右上角控制器可点按、按住和拖动平移/旋转/缩放；文件中的 LevelMesh `render=0` 或 `enabled=0` 不再绘制。`visibleInWorld` 未当作启用开关。完整启动事件和父 Clump 状态仍待恢复。
