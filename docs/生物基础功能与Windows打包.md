# 生物基础功能与 Windows 打包

本版为 Windows x64 编辑器运行包，不包含 Data。修复模型变换时的环境／蜡烛所有者生命周期竞态，补齐离线着色器，并接入原距离 LOD。生物使用原资源尺寸、骨骼、材质和 GLSL；冥龙及遥鲲接入原 FloppySpine，鸟与遥鲲接入 BirdV2 飞行、转向和避障核心。完整游戏世界服务和视觉还原仍未完成。详见 [冥龙骨骼](冥龙骨骼与FloppySpine.md)。

33 张地图识别 477 个生物／生成器对象：143 个鸟、41 个遥鲲、58 个鸟群、140 个螃蟹、13 个冥龙、1 个 Buddy、5 个鱼群、76 个蝴蝶生成器。鸟群按地图保存的容量、生成速度和轨道行进，个体位置与扑翼相位独立，不再使用每群 12 只的预览限制。数量随地图配置与运行时间变化。读取原资源，原地图文件保持不变。

地图打开后自动显示并播放这些生物，原生物预览保留各自启用规则；本次蝴蝶严格保留 SpawnMotes 的 autoStart，不强制启动待事件触发的生成器。鸟与遥鲲恢复部分原自主运动，鸟群使用原运动数值和顶点流；龙、蟹已接入原巡视／自主 AI 核心，地面碰撞与光圈绘制含编辑器适配；Buddy、鱼仍有简化逻辑。缺失幼年遥鲲资源使用已有遥鲲回退；原 Data 缺少 AttribSimpleGlow，冥龙颜色仍有差异，不将缺失资源伪称完整还原。

玩家模式接近时，鸟／遥鲲／鸟群可避让，Buddy 可跟随，螃蟹可冲向玩家，冥龙切换警戒。本次冥龙使用原 spotlight 半径、眼部骨骼、巡视角度和警戒更新顺序，巡视效果沿真实表面投影并遮挡。圈的颜色／混合仍为预览适配，不能当作原地面光圈像素还原。这是基础模拟，尚未复现原版碰撞、锁定计时、攻击伤害、联网、音效和奖励。

顶部“暂停生物”冻结位移与动作，“还原生物”恢复出生位置和默认姿态，再次播放重启动作。切图及重复加载会移除生成的生物、光圈、光束并释放几何体与材质；借用的鱼群模型恢复原状态。晚到的异步资源响应不能重新挂回已清理场景。动画副本单独保存姿态标记，停止时不会污染共享原几何体。

修复了 DuskGraveyard 启动一秒后视口停止的问题：Delay 的下游 AwakenDarkCreatures 尚缺原玩家状态和联网服务，该延时链现在明确显示为不可用，不会进入逐帧事件队列。资源服务接通后仍通过原有依赖刷新流程重新检查事件链。修复后相关生物、蜡烛、Blaze 和环境事件共 18 项回归通过，见 [事件回归](basic-creature-event-regression.json)。

资源覆盖见 [全图审计](basic-creature-audit.json)，实际 Electron／Vulkan 视口验证见 [视口记录](basic-creature-preview-smoke.json)，构建、回归与证据哈希见 [本版验证](basic-creature-verification.json)。实际视口检查覆盖 Dawn 的鸟群／鸟、DayHubCave 的 Buddy／鱼群、DuskGraveyard 的螃蟹／冥龙／遥鲲，以及 Dusk_CrabField 的 128 只螃蟹；检查移动、动画启动、光圈、暂停、还原、重播、切图和原文件不变。

Windows 运行包记录见 [运行包](basic-creature-package.json) 与 [独立包核验](basic-creature-package-verification.json)。运行包带预编译 shader 与 Windows 原生 Vulkan host，不内置 Data。Windows 真机、具体显卡帧率仍未测试。

着色器缓存为 103 组；33 图、2,380 次请求在没有编译工具、用户缓存为空的条件下通过，避免 spawn glslangValidator ENOENT。详见 [全图着色器核验](viewport-shader-bundle-verification.json)。

蜡烛只保留一个点火按钮，使用原 UIFlame 图集区域和 UIRingBigThin 图像。点燃后按钮隐藏，蜡烛原 Flame 渲染保留，不再叠加额外火焰标志。此项复用原画资源，完整原游戏 UI 控制链未复现。

距离 LOD 的 840 个原程序数值对照通过；实际视口验证高→低→高网格切换，保持材质、绘制身份及高精度拾取几何。动态动画资源暂固定 LOD0，远处的原空网格哨兵在编辑器保留最后可用层，防止可编辑物体消失。资源统计表明多层资源仅 43／981，Dawn 全部最低层最多减少约 1.49 倍模型三角面，LOD 单独无法使整图快 10～20 倍。

性能优化包括动画蒙皮合并循环、共享姿态、鸟群顶点流缓存、uniform 布局缓存与光照探针重复计算消除。CPU 局部测量：完整生物动画约 1.50～1.58 倍，万鸟顶点准备约 12.2 倍，uniform 打包约 2.1 倍。这些不能作为整图 FPS。当前测试环境是 Android／PRoot 下的 llvmpipe 软件 Vulkan，云雾和后处理是主要耗时，尚未达到 120 FPS 或整图 10～20 倍。

后续完整原版 AI、世界碰撞、原资源／Model／Barn 所有权、音效、联网与事件生命周期继续使用之前的逆向实现和类进度记录。本版基础预览不将原版完整生物类数从 0 改成完成。

本次实际视口还发现并修复 DuskGraveyard 遥鲲 #1096 的运动中断：SIMD 非几何 W 分量经过归一化产生不同符号的 NaN，编辑器此前漏接原浮点算术服务。现复用已有原程序 16 项算术采样，不改原运动内核，也不对未知 NaN 位模式自行补值。回归覆盖连续运动与还原。
