# 地图加载时 spawn glslangValidator ENOENT 修复

2026-11-25：上一版 95 组预编译缓存漏掉 6 组实际运行源码：Ocean／OceanMesh、OceanDark／OceanDarkMesh、OceanMeshWet、OceanDarkMeshWet、OceanCandle 的视口深度修正版，以及 Flame。原版水面源码的缓存键无法替代经过深度适配的源码。海面还可由 SetOceanRender 启用，不能只按地图是否包含 Water 对象打包。

现在预编译 101 组缓存，覆盖 33 张地图的地形、模型、云、后处理、基础材质、水面与火焰，以及软件／硬件云采样。禁用 PATH 中的编译工具并使用空缓存时，2,322 次着色器请求通过，缺失数为 0；检查不会生成本地编译缓存。范围见 viewport-shader-bundle-verification.json。实际打包应用检查见 shader-bundle-package-smoke.json。

小补丁使用方法：关闭程序，把补丁中的 resources 文件夹复制到 SkyMapEditor.exe 所在目录，合并文件夹并覆盖同名文件，再启动。补丁包含完整的预编译着色器目录；无需安装 Vulkan SDK 或清除用户设置。完整运行包已经包含补丁。

维护源码时先运行 npm run precompile:viewport，再运行 npm run verify:viewport:shaders。打包记录和独立归档核验现在要求全图无编译工具的着色器覆盖检查通过。更改或自行选择不在原地图范围内的着色器，仍可能需要开发用编译工具。
