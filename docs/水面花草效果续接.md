# 水面与花草效果续接 · 2026-11-24

按用户最新优先级推进：水面 → 蜡烛／黑暗植物交互 → 生物。当前开发源码已接入原世界海面网格、局部 Water、FlowerPatch 和 Candle 本体绘制，完整原类验收计数仍为 0。

水面使用真实 `Plane10x10`、原 OceanMesh／雨天／黑暗变体、法线和焦散图片，以及原 WaterSim／WaterSimReset 双附件着色器。256² 模拟保留 GPU 历史，水面读取真实不透明 HDR 和深度；共享运行状态中的位置、缩放与倾斜进入水面矩阵，保留原 Y 偏移和阴影高光参数。CPU 读回参考路径目前省略水与花草，并明确报告此限制，不累计它们的绘制帧数。

花草直接读取 FlowerPatch 和地形三角形，使用原确定性分布、区域裁剪、地表材质筛选、颜色／尺寸编码、初始预生成及完整 Update 子链。动态增生每帧受原 300 候选预算约束，原 32,768 槽池负责分配和回收；原 LOD、初始／动态点淡入淡出、失败回收和映射顶点输出已接入。透明颜色／log-depth 附件通过 GPU 阶段 14 合入现有雾／TAA 流程，共享真实深度。风动和水模拟纹理进入原 Flower 着色器。

原 FlowerTex 是 FlowerBarn 生成的 32×32 RG 纹理，花瓣和草叶使用两个通道。此处不依赖不存在的 Flower.png。点图元与原深度／混合状态分别编码，旧三角形请求保持原字节；材质与完整阶段缓存能区分点和三角形。

- [水面实际可见性](water-map-visibility-check.json)：Dawn、Dusk、SkyHub2、RainForest 均通过。相同相机和确定性帧，保留真实地形／云／深度，分别启用和移除水绘制；变化像素分别为 4,698、12,288、11,887、12,281。各图原文件哈希不变。SkyHub2 原 Ocean 开关为关闭，只绘制局部 Water。
- Dusk 修复前水面 12,288 个像素均有负 RGB，最后为黑图；修复后负 RGB 像素为 0。原因是 Ocean 把视口天空零深度当作零距离，透射权重超出范围。水采样边界将零标记转换为等价的 256,000 米远距离，保留实际表面深度；此转换属于编辑器边界适配，不改写原 shader 文件。
- [纹理 Initialize 对照](flower-texture-oracle.json)：2,576 字节，8 次服务调用，零差异。
- [地表顶点生成对照](flower-vertices-oracle.json)：60 组，249,220 字节，零差异。
- [区域／分布／密度排序／初始预留对照](flower-seeds-oracle.json)：64 组，27,264 字节，零差异。实际排序为密度从高到低。
