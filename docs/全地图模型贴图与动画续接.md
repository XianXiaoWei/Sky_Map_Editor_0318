# 全地图模型贴图与动画续接（2026-11-24）

本轮检查所有地图中带材质、贴图或动画的模型。SkyHub2 的 DistantClouds、CloudSkyDome、FlagDAnim 是检查实例；修复走共用的资源解析、材质绑定、绘制和动画更新路径。

33 张地图的审计覆盖 4,133 个 LevelMesh 和 7,150 个 Beamo／BeamoDecal。全部可解析网格与材质，贴图引用缺失为 0。292 个带骨骼动画的模型、80 种动画资源均可采样默认动作；保存设置要求自动播放的 212 个实例均可启动。其余实例保留地图原播放设置。1,687 个模型的材质使用时间参数，它们通过着色器更新，与骨骼动画分开统计。逐实例字段与资源见 [覆盖审计](model-coverage-audit.json)。

SkyHub2 的五个 FlagDAnim 实例启动默认循环；DistantClouds_02 和 CloudSkyDome_03 使用 SkyboxCloud 原材质、贴图和天空绘制状态。资源声明中 stripAnimation／computeOcclusions／computeEdges 对应的导出后缀参与网格查找，精确文件名优先，避免已存在的预处理资源被误判为缺失。

模型按保存的 animationPlayDefault、animationSpeedMult、animationRandomStartFrame 初始化独立动作请求。没有命名动作表但内嵌资源完整的模型可播放原默认循环。选中模型可选择可用的默认／命名动作，播放、暂停和停止还原；动态更新保留 UV、贴图、颜色、烘焙与索引，并刷新包围盒与透明排序。

237 个模型具有至少一个可用的命名预览动作；未接入的镜像、additive、外部动画依赖和完整分层／事件流程仍保留限制。单帧动作或保存为不播放的模型不会被强制改成持续运动。

天空／Ghostly 绘制组、保存 FogVolume 的原几何和强度、雾生成与合成均已接入视口。湿地与沙地模型缺少的水面输入已补齐，未模拟的 PuddleSim 采用明确的零梯度重置输入；真实雨滴模拟仍待接。无兼容保存烘焙时使用原默认光照编码的预览输入，场景探针仍是编辑器适配。生物遮蔽通道为零会导致 Vulkan log2／插值产生非有限值，仅对已校验的对应顶点程序加入零端点数值保护；正的 UNORM8 通道保持原表达式。原资源和 shader 文件没有改写，未宣称与原 Metal 画面逐像素一致。

预编译包覆盖全图模型及 WaterSim、WaterSimReset、Ocean、Flower、Candle 和水／花背景复制程序。空 PATH、空可写缓存检查验证加载内置 SPIR-V，无需用户安装 shader 编译器。最终验收与本次构建精确哈希见 [模型验证](model-coverage-verification.json)。工作区的 [桌面包验证](preview-package-verification.json) 保存外部归档核验；ZIP 内的载荷哈希见包根目录 `预览构建信息.json`，归档 SHA 另附同名 `.sha256` 文件。

CarryLand3 没有 LevelMesh，仍需验证其 Beamo 地图装载；默认检查名单现取完整地图目录，避免仅从 LevelMesh 行推导地图造成遗漏。

Storm 首轮检查暴露了仅有独立 Flame、没有 Candle 的边界：原 CandleBarn.Render 仍发出三次零字节分配／释放，编辑器临时分配器用 Set 记录地址时合并了这些请求，第二次释放导致整帧失败。现按地址记录分配次数，每次释放消耗一次所有权，保留原调用顺序和越界／未持有地址检查。新增零字节、零／正字节共享地址及正字节对齐／容量回归；随后重新构建并执行完整 33 图检查。

连续单进程检查曾在切图后遇到 Electron 进程退出，未将未完成的运行记为通过。最终检查按每批最多三图使用独立进程，保留每批结果、SHA 和同一构建指纹，再核对合并后的地图名单完整覆盖 33 图。可用 `node tools/model-coverage-batches.mjs --resume` 在构建未变化时续跑已校验的批次。

最终同一构建的 33 图检查由 17 个成功进程批次组成，末段按单图进程续测。9 项代表材质实际 GPU 出图、591 项项目回归及 TypeScript 检查通过；95 组预编译缓存、33 图的 480 次模型／效果请求在空 PATH 下通过。未完成或失败的运行没有合并为通过记录。Windows 宿主完成 AMD64 交叉构建，真机运行和显卡帧率仍未验收。
