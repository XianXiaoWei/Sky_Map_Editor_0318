## 索引与资源依赖

全部 33 地图 10,653 条 Mesh.bin 烘焙记录已经清点，10,592 条可按原对象 GUID/资源名关联，61 条未关联保留。原查找函数按 GUID 返回首个记录，不按资源名查找；11,710 次原查询与三个明确兼容指令子段已通过。[报告](baked-lookup-oracle.json) 仅验证明确 loaded-table 快照；未代表三个消费入口完整运行。

| 所属类 | 索引/字段 | 完整验收尚缺 |
| --- | --- | --- |
| LevelMesh | resourceName、bstGuid、LOD、material、shaderName、shaderParams → LevelMeshShaderParam；参数 texValue 指向纹理名 | 原资源加载状态、GUID 虚方法来源、采样展开与绑定、Skirt/Visibility、原材质批次/纹理资源、实例初始化/更新/注销 |
| Beamo | meshName、bstGuid、materialBstGuid/materialBstGuidSecondary、LOD、occlusionEnable、skirtHeight | BeamoBarn 完整创建、材质 GUID 实际运行索引、动态变换/LOD/遮挡/裙边提交、原绘制/释放 |
| BeamoDecal | meshName、bstGuid、materialBstGuid、disableDist、transform | 贴花完整加载/距离禁用/变换/材质及深度状态/销毁 |
| CloudCard | 原模型/烘焙、连接组、世界球/动态顶点 | 对象自动注册、完整照明/风场/遮挡、真实绘制与生命周期 |
| LevelMaterial | bstGuid、material、shaderName、shaderParams → LevelShaderParam、physicsMaterialOverride | 完整材质索引、动态参数更新、渲染与物理材质绑定和卸载 |

LevelMesh/Beamo 等直接序列化引用数组为空，不表示无依赖。网格/材质 GUID、资源字符串、嵌套 shader 参数、Clump/PlayAnimation/Timeline 等反向对象引用都需要独立验收，不能只统计 TGCL reference 字段。

## 动画与功能逻辑

LevelMesh 的 animated、animationPlayDefault、animationRandomStartFrame、animationSpeedMult、charAnimPack1/2、preprocessAnimation/File、stripAnimation、morphable、clothPhysics/Gravity、vertSprings/Coef、floppySpine、motionBlur 等字段已定位与保留。它们的完整原 Motion/骨骼/形变/布料/弹簧/运动模糊行为没有因“能显示静态网格”而完成。

- 默认播放、随机起帧、速度倍率、具体 anim pack/sequence 选择：未完成原加载/更新全链。
- PlayAnimation 目标引用、速度 Float、默认/序列动画、开始/切换/结束事件：未完成原驱动。
- Timeline 的 duration/loop/skippable/timeNodes/onSkip，以及 TimelineNode 的事件顺序：未完成原时间与派发逻辑。
- TransformObject/Parent/MoveObjectAlongRail/RotateObject 与 Clump 的启用反馈：未完成完整对象生命周期；Rail 有明确样条/缓存子链核验。
- SetMeshShaderParam 的 changeTime/staggerDelay/各参数类型、纹理与 Float 输入：未完成完整动态材质原逻辑。
- render/enabled、碰撞、阴影、camera occlusion、LOD、裙边、可见性与注销：需要在原创建/调度/资源环境连续核验。

本轮恢复 EventBarn 正常调度并连续调用 FloatAdd 与依赖音效，为模型事件/动画控制链提供已核验的基础；没有将尚未接入的模型/动画类计为完成。[调度证据](event-barn-oracle.json)。
