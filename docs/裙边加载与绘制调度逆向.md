# SkirtBarn 加载几何、绘制驱动与终止

本轮按五段同等优先的要求恢复裙边原运行子链。最终标准仍是 100% 还原原游戏逻辑；这份报告只证明明确输入和依赖服务下的原 CPU 输出，不代替真实资源、摄像机、GPU 或完整类验收。

[原函数对照报告](skirt-barn-oracle.json)通过：83 组、45,939,862 项比较、0 差异，覆盖 33 张地图全部 2,533 条裙边、363,788 个顶点、1,339,572 个索引。原函数产生的 4,415 个绘制 chunk 也一致。全部真实记录分别使用 0 和 0x55 两种显式堆初始值；另有空记录、奇偶条数、SIMD/标量索引、NaN、正负零、全局索引超过 u16、已有索引计数、关闭绘制及加载待完成状态。

## 原函数及实际行为

| 原函数 | 本轮范围 |
| --- | --- |
| `0x1005abf50` | 未修改的 Initialize 正常已找到资源路径及 `LevelData+0x120` 提前返回路径；外部服务显式提供 |
| `0x10043fb70` / `0x100443560` | 原 30 项材质定义、地图覆盖及按序号查询，原函数连续执行 |
| `0x1005acaf0` | 未修改的绘制驱动，实际视锥/Camera/距离查询结果显式提供 |
| `0x1007f6ae0` | 原非空范围追加与相邻 chunk 合并；正常范围核验 |
| `0x1005aca70` | 未修改的 Terminate 正常路径与重复终止；外部释放/销毁显式提供 |

Initialize 把资源中每条 32-byte 加载记录的 40-byte 顶点拆成 slot 0 的前 36 字节和 slot 3 的末 4 字节；另分配 slot 2 的每顶点 4 字节，但整个函数没有写入它。这条流保留明确堆快照，不能自行填入猜测属性。原类型/属性描述均从实际调用参数提取，slot 0 属性为 `[1,3,32,33,13,14,15]`，slot 2/3 分别为 24/25。

每条局部 u16 索引加上之前记录的顶点总数，写入合并 u32 索引流。`Barn+0x1c` 顶点总数重置；`Barn+0x20` 索引总数累加原值。因此，已有非零索引计数会留下未写入的分配尾部，本轮保持这些字节，未把累加行为改成清零。

每条运行记录为 48 字节：XYZ 最小/最大值分别从 `+0/+0x10` 开始，`+0x20` 为索引数，`+0x24` 为材质掩码，`+0x28..0x2f` 未写入。包围盒使用原 MIN/MAX 第二操作数优先的 NaN/相等规则，区别于另一个 Skirterator 的跳过 NaN 规则。两个 W 分量来自未指定的 SIMD 状态，本轮排除，不赋予几何语义。

材质掩码检查所有顶点的四个非零 ID，不检查权重，也不因前面的零 ID 停止。原材质表没有的 ID 不产生位；并非每个未知 ID 都触发原函数错误。每项材质按原顺序建立 `shaderName + AlphaSkirt`，设置 `u_skirtDRange=5`，调用原材质上传入口。

绘制启用时先清空每个材质队列；对每条记录依次检查原视锥和距 Camera 包围盒距离（原常量 40）。只有两项通过才按材质位追加原完整索引范围；被拒绝的记录仍推进索引起点。全部条目处理后按材质顺序 flush。相邻可见范围合并，空索引不产生 chunk。原追加函数还有空队列 `start=FFFFFFFF` 的隐藏槽路径，本轮正常范围适配器明确拒绝，未把未测试分支伪装成已恢复。

Terminate 先逐材质销毁，再终止几何，清空顶点/索引/材质计数，最后释放运行记录。它保留 `Barn+0x18` 裙边条数和分配器；再次终止仍调用几何终止，但不重复释放记录。
