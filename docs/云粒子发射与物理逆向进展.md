插入写 position.xyz、0.8×input velocity、原 input velocity 的长度、size 与 life=1。+0x9018 的 12 字节 tuple 已确认是 `[initial size, opacityMult, phase]`。phase 使用 float32(rand)×2^-31；RAND_MAX 舍入后会恰为 1，不额外 clamp。

模型辅助的 direction 各分量为 float32(rand)×2^-31×4−2，长度大于 float32(1e-5) 才归一化。径向系数为 `(1−u)×0.001+u×0.999`；size=speed×0.425，spread=size×0.667。opacity 为 `0.5×[value×clamp(value)+pow(value,1.5)×(1−clamp(value))]`，每次乘加保留原 float32 顺序。

每次模型发射尝试先消耗四个随机数，插入成功再消耗 phase 的随机数。两次均成功共 10 次，只成功一次为 9 次，满环两次均拒绝仍消耗 8 次。接口要求调用方提供原 31-bit 随机数序列，没有用本地生成器替代游戏全局 RNG。

双发射辅助的距离响应目标为 distance>0 时 1，否则 clamp((distance+2)/3)，随后平方。目标升高即时更新，下降使用 delta×(previous>0.05 ?0.5:0.05)，保留原比较/夹取分支。

## 最近三个交互源

`selectCloudParticleSources` 恢复 `0x100226920..0x100226fc2`。每个粒子的 position.xyz 对原 192 字节临时 source 的 previous vec4（+0）求差，距离按 `z²+(x²+y²)` 的 float32 顺序计算。范围为 `(float32(float32(1.5×source[+0x8c])×source[+0x90]))²`；相等保留，原 unordered 比较亦保留。

候选按 source 顺序压缩，再对最多三个候选建最大堆；后续只有严格更近的候选才替换堆顶。最后按原堆流程排序。相同距离在下沉过程中会移动，不能用全量稳定排序替代。

物理队列的 radius 在临时 source 的 **+0x94**，不是筛选用的 +0x8c。当前筛选接口使用两个明确范围字段，避免把队列 radius 错当筛选半径；Avatar 和队列到完整 192 字节 source 的准备过程仍需恢复。

[筛选 oracle](cloud-particle-selection-oracle.json) 共 **593 组**，覆盖 0..48 source、相同距离、升降序、剔除/范围相邻 float32、非零 W 和有限输入乘法溢出。完整候选排列、source index、offset.xyzw 和 squared distance 字节一致。计数捕获跳接重放被覆盖的原指令，筛选/堆指令保留。普通稳定排序在 **275 组**产生不同的最近三个顺序。零候选返回空列表，不制造交互球。

## 原积分

`stepCloudParticlePhysics` 恢复 exp 权重 `0x100226839..0x1002268db` 与尾积分/约束 `0x10022757e..0x100227885`。前序 `0x100227000..0x100227552` 的 forceVelocity、forceVector、minimumDistance 与选中 sphere 仍为明确输入。

- 原速度与 speed 的 exp rate 分别为 −18.858261108398438 和 −27.488723754882812。保留 `weight=1−exp`、`remaining=1−weight` 的抵消边界。
- 速度目标包含 **forceVector+forceVelocity**，再乘 0.8 并按权重平滑；speed 用平滑速度长度/0.8。
- 径向投影、sphere 约束系数 0.08249999582767487、距离 gate 与原 −0.4 speed gate 均保留。低速方向缺省为 [0,1,0]，阈值 0.001。
- 新位置由原 displacement 更新，写回 velocity 是约束 velocity **减 displacement**；没有改成常见物理积分公式。
- size 按相对移动的径向投影增长，最低 0.25×delta；实例前序 vector 为 forceVector×0.15。

[积分 oracle](cloud-particle-physics-oracle.json) 共 **400 组**，新位置、剩余 velocity、speed、size 与实例 vector 字节全部一致。前序交互为明确输入，原 expf 绑定 Linux libm 并捕获；生产 JS exp 在这些案例也逐 bit 一致。此结果不包含完整 Update、原 Mac libm、Metal 或游戏画面对照。
