# EnvironmentForces 全局阵风

已恢复原 Update 中 `0x100326666..0x1003273b6` 的全局风核心：三倍频整数噪声、环境强度及两个累计相位、方向和强度变化、显式 SetWind 覆盖分支、指数平滑及边界力叠加。256 组、2,304 个 float32 分量与原指令子段和明确的数学回调结果逐字节一致。

主视口仍未自动接入完整风场。该范围不包含完整 Update、SetWind 自动事件、初始运行状态、边界力来源、玩家/粒子来源或原游戏验收。

| +0x0c | 原缩放/夹取后的帧时间 |
| +0x10 | 显式覆盖风向量 |

| +0x58 / +0x5c | 替代目标强度及选择标志 |

默认环境风强度 tweak `kAmbientWind` 的存储地址为 `0x100cac150`；原文件初值 8.5，注册范围为 1.5–8.5。运行时 tweak 加载/事件仍待恢复。实现要求调用者明确供给选中的目标值，未擅自采用地图最终运行默认值。

SetWind 在数据中有 4 个对象，原字段包括 windForce、windDir、windTarget、useWindTarget、windRegions、useWindRegions 和 fireOnce。这里只恢复已有覆盖向量输入的分支；完整对象如何生成该向量尚未实现。

## 核心运算

整数噪声使用原 31-bit hash 和 float32 换算，以余数乘原 float32 π，经 cosf 做余弦插值。三个倍频为 1、2、4；不同用途分别使用原 0.333/0.110889 或 0.25/0.0625 权重，保留全部浮点舍入顺序。

时间/30 产生基础方向变化。强度按 `1-exp(delta * -1.01704740524292)` 平滑到选中的环境风目标，再经强度/10 夹取产生两个相位的推进速度。相位噪声改变方向和强度；时间/10 噪声提供另一层慢变化。

显式覆盖模式保留环境强度和相位，直接采用供给的覆盖向量。最终两种模式均按 `1-exp(delta * -6.694305896759033)` 平滑到目标向量，再叠加前序原边界查询的力。

## 数学精度及验证边界

原指令保留在原地址，以明确入口和 RET 出口执行；原 cosf、expf、sincosf 导入绑定 Linux libc。全部调用参数和返回值被捕获，恢复代码消费原数学返回值的结果精确通过。没有将这一子段称为完整函数恢复。

float32 舍入的 JavaScript Math 默认预览实现单独对照，有 1/256 个场景与 Linux libc 回调不同。完整失败状态、输入和输出保存在 [environment-gust-oracle.json](environment-gust-oracle.json)。不能据此宣称 macOS libm 或原游戏画面一致。
