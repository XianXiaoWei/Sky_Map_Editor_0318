# 模型缺贴图与自然物品续接（2026-11-23）

后续事件实现、45 个新增可运行实例和 511 项回归的结果见 [生物环境物品事件续接](生物环境物品事件续接.md)。本页保留上一轮贴图、探针与 Candle 构造检查的原始结论。

本轮按用户指定顺序：先排查部分模型没有贴图，再推进生物、蜡烛、黑暗植物和环境相关类。

33 图的原贴图别名已在上一轮恢复。这次发现方向光和透明材质被 `u_averageProbeColor` 的场景全局绑定缺口阻断，图片文件和保存参数本身存在。恢复原 Scene 的 uniform 身份、类型和所有权，将现有大气预览探针的 diffuse 输入送入模型材质。使用原 shader、原 PNG、原顶点和原采样配置；探针光照仍是明确的编辑器大气适配，原场景射线／交点光照尚未完成。

静态材质依赖满足由 **3398 → 3742**，新增 **344** 个；保存 render/enabled 允许初始显示由 **2837 → 3065**，新增 **228** 个。逐对象变化和仍被阻断的原因见 [检查记录](model-texture-continuation.json)。这些数量是依赖检查，不是完整原模型／类运行验收。

七种原材质已实际 GPU 出图：DirectionalLighting、DirectionalLightingNoUv、LitAlpha、LitAlphaColor、LitAlphaTest、LitAlphaDual、LitAlphaFading。上传图片的基础 mip 与原 PNG 解码逐字节一致；时间更新复用已上传几何和纹理。原 `u_alphaFade=1` 会隐藏透明特效，验证选择原本有输出的保存实例，没有改原 alpha 参数或 shader 来通过检查。图像、对象、纹理与输出 SHA 见 [GPU 检查](model-probe-gpu-check.json)。

六个 CreatureSl / MoteKeyDiamond05 的原输入在初步 GPU 检查中出现非有限片元，继续保留 SH 依赖阻断。动画／蒙皮、水／puddle、Skybox／Ghostly／FogVolume 和真实缺失的 mesh 仍需各自恢复，不把灰色或白色诊断显示记为原材质成功。

蜡烛现在使用原 CandleBarn 的 196 槽、176 字节步长，全部 **1077** 个保存实例进入共享地址空间。原 CandleObject 普通构造 `0x1001ec650` 的 class ID 写在 **+0**；Flame 和物品 Event 的 Object 在 +8，两者不能混用。原构造五类／30 组／1,968,168 比较字节零差异，见 [原构造对照](object-item-construction-oracle.json)。矩阵字节入口保留原逐列别名复制顺序，并复核全部保存蜡烛矩阵。

缺省 enabled=true、numWaxToGive=1、meshType=kCandleMesh_Default 按原字段标签恢复；Default enum 的名称和零值来自原注册 `0x1001ee7f6 / 0x1001ee82e`。保存字段优先。Candle 的真实渲染记录尚未装载时，启用操作在改变对象前返回阻断，避免写入假记录；原资源装载、点燃／熄灭、蜡量和绘制仍待接入。

生物和自然对象全图审计现覆盖 BirdV2 184、Crab 140、BirdFlock 58、DarkCreature 13、Flame 290、OnFlame 154、SetFlame 43、FlowerPatch 582 和 CandleObject 1077。24,730 个保存标量字段、1,191 个共享引用通过；324 个鸟／蟹实例能追踪到保存 meshType。植物追踪包含 **1012** 个 Darkshroom 模型和 **7** 个 CharEnvFlower 动画模型，不能把它们统称为已经能燃烧的黑暗植物。完整字段、资源与控制引用见 [自然对象审计](objects-nature-audit.json)。

后续依赖入口已经固定：CandleBarn 原 OnLevelLoad／Candle 渲染记录与资源表；FlameBarn 原装载和 SetFlame／OnFlame 对 Flame、Candle、Clump 的转换与更新；生物 Barn 的动画／AI／碰撞；FlowerBarn 地表采样和顶点生成；Ocean 模拟与水面绘制。黑暗植物需沿实际 Clump／Parent／事件引用恢复，不能按模型名称推定燃烧行为。完整原类／实例验收仍为 0。
