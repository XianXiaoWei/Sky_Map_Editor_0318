# 蜡烛逻辑与绘制续接 · 2026-11-24

当前源码中的 CandleObject 已绑定共享 CandleBarn 原布局记录、Candle RenderData 与独立 Flame 槽，原蜡烛本体绘制进入真实不透明 RGBDepth 和深度附件，位于水面折射、透明花草与雾／TAA 之前。开关写入原记录，移动写入原保存矩阵；逐帧更新调用原 CandleBarn.Update 的已核验移植。此进度不计为完整原类验收。

本体使用 `CandleDefault_CompOcc`、`Candles_02`、`CandlePlayer_CompOcc` 的原打包顶点和原 Candle GLSL，按原六项模板表选择网格、OBB、大小和颜色。该 shader 的蜡材质读取顶点颜色及 `u_color`，没有二维贴图采样器；不能把不存在的贴图槽当作蜡烛缺图，也没有额外套用 CandleTex。天空探针和无遮挡环境亮度仍是明确的预览输入。

原生对照 [candle-load-oracle.json](candle-load-oracle.json) 执行 SHA256 校验后的原 Sky 可执行文件，比较 286 组、113,572,312 字节、1,472 次服务调用，零差异。覆盖正常 Load／Create／Update／Render、Candle／Flame 的重叠变换、池断言、地面投影、标识符点燃、特效／通知顺序、Flame 强度和熄灭音效参数，包含单帧和连续多帧。新增 Flame.Load／Unload、CandleBarn.OnLevelUnload 和 Flame.Update 运动／亮度前段。前段对照只将后续交互入口跳转到原函数尾声，未宣称验证完整 Update。资源、碰撞、macOS libm 返回、音效、网络、Visibility、GPU 和内存分配以明示服务供给；工具调试 UI 关闭。

对照修正了地面探测半径取第二根缩放轴的问题。原强度 NaN 比较跳过熄灭，边界值和正负零按原 SSE 分支保留。蜡量消耗维持原时间上下限、消耗时的垂直缩短和燃尽后标记，不额外添加编辑器自行设计的消耗规则。

[完整地形／云／水／花草／蜡烛检查](full-water-flower-candle-scene-check.json) 覆盖 Dawn、SkyHub2、WorldEmpty 共 18 帧，包括窗口缩放、切图和渲染器重启，GPU 执行方式间最终字节零差异。[近距离检查](candle-map-gpu-check.json) 通过 Dawn 8 个、SkyHub2 138 个 Candle 的共享记录与各 6 帧开关、点燃计时、变换、缩放和源文件不变检查。相同相机／uniform 下单独关闭 Candle 批次，去除地形／花草／时间抖动后分别确认 47、164 个本体像素发生变化，截图：[Dawn 本体](candle-body-Dawn.png)、[SkyHub2 本体](candle-body-SkyHub2.png)；实际场景：[Dawn](candle-map-Dawn.png)、[SkyHub2](candle-map-SkyHub2.png)。Linux 软件 Vulkan 的结果不等同于原游戏整图或真机验收。

本轮新增共享资源迟到、原事件链、消费状态与卸载顺序集成测试，项目回归 554／554 通过；TypeScript 检查与桌面构建通过。

Flame 池步长纠正为原 `0x1b0`，每个蜡烛子 Flame 调用原父构造和完整 Load，独立地图 Flame 也执行同一 Load。原两次 rand 的转换、局部矩阵、加载标志、强度和音效句柄初始化已恢复。rand31 序列由编辑器明确提供；音效请求进入待分派队列，未装载音频时返回空句柄。

Flame.Update 的已对照前段恢复当前位置／前一位置速度、指数位置滞后及最大偏移、强度到亮度／半径的转换和消耗值递减。实际编辑器按共享时钟调用此段，并用结果驱动原 Candle 的颜色／亮度；JS expf／powf 是明示编辑器服务。后段的水／风／Avatar／点燃传播／音效／粒子仍未代替成编辑器规则。

SetFlame 现在可以操作真实 Candle 记录；具有可用下游启用链的 OnFlame 在资源附着后动态注册到原 EventBarn。已有事件槽、状态和计时保持不变，新增事件仍按原 autoStart 请求启动。Rain #898 的 OnFlame 已通过集成验证：消费真实蜡烛记录、设置消耗时间并启动 SetFlame 下游，文档保存字节不变。下游 DialogHint、Timeline、SpawnMotes 等生命周期未接入时，该事件仍明确不可用。

卸载先停事件，再运行原 CandleBarn.OnLevelUnload 与 Flame.Unload，最后释放编辑器对象地址空间。Flame 音效／粒子句柄按原身份核验后停止，保留原句柄字段；Candle Vertex 的资源释放仍是明示编辑器服务。原 Initialize 的资源观察／合并网格／GPU owner、FlameBarn 完整 Update 与火焰图元、实际音效／特效／网络／奖励分派和完整资源链仍待接入。完整原类验收计数仍为 0。

[Rain 真实地图检查](candle-event-rain-gpu-check.json) 已通过：12 个 Candle、9 个可见本体、6 帧，原 OnFlame #898／#1717 和 5 个 SetFlame 在资源就绪后可用。检查触发真实 #1159，确认蜡烛亮度／发光半径大于零，并核验共享时钟只前进一次。独立本体批次确认 227 个像素；开关、变换、缩放和地图源文件保留通过。Rain 湿水面额外采样器 `u_puddleSimNorm` 缺失会使整帧失败，本轮已绑定与湿地形一致的原 UpNormal 预览资源；真实 PuddleSim 雨滴模拟继续待接入。

后续全地图检查发现 Storm 只有独立 Flame、没有 Candle 时，原 Render 的三个零字节临时分配可能共用地址。编辑器 Set 记录合并了这些请求，导致重复释放报错并阻断整帧。临时分配器已改为按地址记录请求次数，保留三次释放及未持有地址检查；3 项专项回归和 Storm 实际视口通过，完整项目回归 591／591 通过。此修复不表示 Flame 后段、火焰图元或完整蜡烛交互已完成；全图与桌面包的最终记录见 [模型续接](全地图模型贴图与动画续接.md)。
