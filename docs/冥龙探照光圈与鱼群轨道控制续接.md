# 冥龙探照光圈与鱼群轨道控制续接

本次恢复冥龙外层更新的眼部与探照阶段 `0x10026e7da..0x10026f41e`，并补齐鱼群轨道更新前段和共用 SafeSlerp。原程序对照合计 **1762 个用例、179267136 字节、17857 次服务／数学调用，零差异**。

冥龙巡视光圈已恢复的计算包括：按速度或警戒目标生成眼部朝向，警戒扫动、缓存四元数与最短路径插值，眼部模型变换，旋转探照方向，向地面发射原查询参数的射线，按玩家／鸟目标改写落点，投射位置平滑，以及警戒计时从半径 10 收缩至 2.5。保留两次环境颜色查询、`u_diffuseColor` 写入、检测 Marker 的位置／半径变换和旧效果到期清除。

眼部和投射共 **504 个用例、68136704 字节、12965 次有序调用**，其中 244 个独立投射用例和 260 个眼部→投射连续组合用例。覆盖 64 鸟槽边界、缺失目标、射线命中／未命中、状态与连续帧、零／负值／NaN、回调后的字段重读和私有查询 padding。对照采用原指令体，数学函数参数与顺序核对后重放 native Linux libc 返回值；`sincosf_stret` 的 upper lanes 单独输入，不声称 JavaScript／macOS libm 等价。

鱼群 `MoveObjectAlongRail.Update` 前段 `0x100484a90..0x100484fc0` 共 **338 个用例、110994208 字节、1820 次调用**。恢复联网启停、权威检查、两种 double 时钟、跟随玩家与轨道进度约束、缓入缓出、指数平滑及空列表结束路径。有对象的路径在对象移动循环前结束，未推进计数，不能作为完整 Update。

完整 `TGCMath.SafeSlerp 0x100111b90..0x100111f30` 共 **920 个用例、136224 字节、3072 次数学调用**。涵盖反向向量、preferred/Z/Y 轴选择、扰动、非有限比例回退、输出别名、XYZ/W 归一化和原断言；它将用于鱼群对象转向。
