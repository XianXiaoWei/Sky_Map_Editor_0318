# 环境原构造与共享状态

EnvNode 整个普通构造、Ambience 太阳派生子链及视口共享环境 owner 已补上。保存／默认参数、真实内核、编辑器环境预览分别记录；完整环境类验收仍未完成。

EnvNode placement 为 `0x10031c830`，1040 字节。原构造不写 enabled、transform 和部分 private 字段；这些字段不再被猜测初始化。缺 enabled 保存字段使用原 TGCL tag 的 true。未注册默认环境时，混合器保留上次输出；初始输出来自原 Ambience initializer。原 Color initializer 的白色为 `[1,1,1,1]`。

Ambience 太阳派生范围 `0x10005b39c..0x10005b6e2`，方向 helper `0x100064550`，天空 Gaussian sampler `0x100064820`。普通天空透射、染色和 intensity 路径已恢复；cheapFog 保留传入 sunColor。

`EnvironmentRuntime.advance` 推进计时，`sample` 采样同一状态。天空、模型和云共用同一个 viewport owner。暂停和相机重绘不会额外推进计时；运行启停不改 Objects 保存字段；切图重建 owner。IPC 为 `environmentRuntimeInfo`／`setEnvironmentEnabled`。
