# Avatar 位置震动与 Objects 相机推进（2026-11-18）

本轮接上 `SetCameraShake` 写出的 speed、force、weight，恢复完整 Whisker 震动/旋转基底辅助函数 `0x10073afd0`，在独立 Avatar 相机上显示原三轴位置噪声。`SetCameraKeyFrameShake` 继续更新实际 Clump 中的关键帧参数，关键帧震动显示待恢复。

[原机器码核验](avatar-camera-shake-oracle.json)：162 组、1,296 帧、2,126,416 比较字节，零差异。覆盖全部 1024 字节相机状态、三轴位置偏移、三个旋转基底向量、Wind 查询位置、四次射线请求和 128 + 432 字节擦身音效参数；含全部 10 条真实 SetCameraShake speed/force 配置。浮点输入以原十六进制保存负零，逐帧捕获并重放原 Linux libm 的 expf、powf、cosf 和 sincos 返回及显式 SIMD 上部通道，不宣称 macOS libm 一致。

函数体共 604 条指令，原调用方共 2,260 条指令。完整边界、SHA、常量及原调用点见 [函数证据](avatar-camera-shake-native.json)。只有辅助函数经过完整原机器码执行；外围 Update 的反汇编不能代替其运行验收。原程序 SHA256 保持 `3fa493e2542638299fd54d64e1b62aeb5b81c8f290176d955c3e38a27fa72b20`。

| 原行为 | 恢复内容 |
| --- | --- |
| 基础震动 | 原物理位移、四次射线距离、相对 Wind/速度能量及 float32 平滑 |
| 事件混合 | 权重六次幂混合 speed，五次幂混合 force；原 expf 权重衰减 |
| 相位推进 | 三轴使用 53、61、49 及原 0.3 系数 |
| 噪声 | 原 32 位整数哈希、余弦插值、三层频率及原 0.333 / 0.110889 权重 |
| 镜头输出 | 三轴位置偏移及单独的旋转基底；原调用方将偏移加到眼位置后交给避障 |
| 擦身请求 | 按原距离/速度条件生成 whippast 的完整已初始化参数；实际音效播放仍为服务 |

原噪声用截断转整数，再将低 32 位按无符号数转换回浮点；负相位的原行为完整保留，没有改为 floor。当前核验仅覆盖有限输入、全部噪声整数转换在 int32 范围内。射线结果、物理字段、Wind 输出与音效分发是显式服务；原射线对象过滤、碰撞/避障及完整风场消费链尚未闭合。实际配置中的遗漏字段仍只在 oracle 使用明确的零准备值，不被认作原构造默认值。

原函数在旋转临时通道中写 `noise * 0`，位置偏移另行返回。外围调用方在 `0x100740eab` 加入眼位置，随后调用 `0x10073d880` 避障。编辑器采用已恢复的三轴位置偏移；输入、连续跟随、相机基准位置、lookAt 和投影仍为预览适配，未将辅助函数的原旋转基底冒充完整最终相机。

Avatar 面板手动运行 SetCameraShake 后显示位置震动。预览明确提供中性物理/stance、零 Wind、无射线命中和无音效播放，以及浏览器数学服务；角色移动速度来自现有移动预览。原自动场景事件和原物理行为另验。每帧移除旧偏移后再加新偏移，暂停时保持本帧偏移，停止后恢复相机基准位置；相机控制输入会重新建立基准位置。模式和地图切换清理会话，编辑相机独立保存。

[实际 Electron/Vulkan 检查](avatar-camera-shake-smoke.json) 验证位置震动进入真实视口、相机朝向保持一致、暂停冻结、停止恢复以及连续三次重启无漂移，并覆盖两类事件、模式/地图切换及编辑数据未变脏。[截图](avatar-camera-shake-preview.png)。256 项测试、类型检查和构建通过。已核验核心子链仍为 20 类；该工作补全已有 SetCameraShake 的消费依赖，不增加完整类计数。完整原类运行 0 类，清单 850/2830 项（30.04%）不代表玩法完成度。
